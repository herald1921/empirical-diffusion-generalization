late-collapse detection, or an optimization rule in the checked plotting and
numerics code. It uses the manually specified eta=0.16:

- upstream_repo/section_05_early_stopping/numerics/make_figures.py:108 calls B

- upstream_repo/section_05_early_stopping/numerics/prepare_insets.py:14 does

  It is not the B selection rule.

The original target is slightly nonuniform. Reusing eta/R=.08 for the uniform
target preserves a number, not an independently justified selection rule.
For the current target it still lies in the circle-topology interval with G=0.

3. RECOMMENDATION, EXPLICITLY A NEW CHOICE
If B is meant to show a visibly later, fragmented regime while retaining the
original 'later stop: harms' meaning, eta/R=.02 (eta=.04) is a useful choice:
there are 16 disconnected sample neighborhoods, G is about0.4723 S_N, and
denoising increases total error by about0.1533 S_N. It avoids placing B almost
on the eta=0 endpoint, where labels overlap and the raw/denoised contrast is
small. It is a transparent representative scale, not the original algorithm.

If a rule-based choice is desired, the explicitly new criterion G(r_B)=S_N/2
has the unique solution eta_B/R=0.01880935924777692 (eta_B=0.03761871849555384).
This guarantees a definite geometric diversity deficit and a fragmented
neighborhood. Its exact transport readout has not yet been run; the nearby
eta=.04 result above is verified. Do not present this criterion as historical.

If instead B must preserve only the original comparison and also have a
numerically resolved denoised W2<S_N, eta/R=.055 is the verified alternative.
It remains topologically correct with G=0, so it cannot illustrate topology
fragmentation. Selecting the maximizer of denoised-minus-raw error would also
be a new optimization rule, absent from the original release.
